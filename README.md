# 🛒 かいもの — 家族用 買い物リスト

家族でスーパーへ行くときの買い物リストを、名前をつけて作成・共有できるWebアプリ。
食材名・個数・カテゴリを管理でき、URLを送るだけで家族と共有できます。

**本番URL**: https://kaimono-qe4t.vercel.app

<br>

## ✨ できること

| 機能 | 説明 |
|---|---|
| 📝 リスト作成・共有 | リスト名をつけて作成。URLを送るだけで家族と共有 |
| ✅ チェック・進捗表示 | 買ったものにチェック。上部に進捗バー |
| 🥦 **カテゴリ自動判定** | 食材名を入力すると、やさい・肉・魚などを自動で振り分け |
| 💡 **画面スリープ防止** | 買い物中に画面が消えないトグル（対応端末のみ） |
| 🔁 リスト再利用 | 完了したリストのチェックをまとめて外して、また使える |
| 📋 テキストコピー | カテゴリ別に整形して、LINEなどに貼り付けやすくコピー |
| 📱 ホーム画面に追加 | PWA対応。スマホのホーム画面からアプリのように起動 |

<br>

## 🎩 「にんじん」が勝手に「やさい」になる仕組み

このアプリの隠れた目玉。でも実は **AIでも機械学習でもなく、手書きの辞書で照合しているだけ** です。
シンプルだからこそ「ネットなしで一瞬」「同じ入力なら必ず同じ結果」「1行足せば覚える」という良さがあります。

処理は3ステップ（[`lib/autoCategory.ts`](lib/autoCategory.ts)）:

**1. 入力をそろえる（表記ゆれ対策）**
`ニンジン` も `ﾆﾝｼﾞﾝ` も、正規化してから照合。カタカナ→ひらがな変換で `ニンジン` → `にんじん`。

**2. 手書きの辞書と部分一致**
```ts
"にんじん": "やさい",  "人参": "やさい",
"鶏":      "肉",     "さば":  "魚",  ...  // 約200語
```
「採れたてにんじん3本」のように前後に文字があっても、`にんじん` を含むのでヒット。

**3. 誤爆を防ぐ2つの工夫**

部分一致は素直にやると事故ります👇

| 入力 | 素直にやると… | 対策後 |
|---|---|---|
| スイカ | 「**いか**」で魚判定 🐟 | その他（無理に判定しない） |
| バニラ | 「**にら**」でやさい判定 🥦 | その他 |
| フライパン | 「**パン**」で穀物判定 🍞 | 日用品 |

- **長いキーワードを優先**して照合（`フライパン` を先に見るので `パン` に負けない）
- **わざと「判定しない」登録**（`スイカ → null`）で紛らわしい語を遮断

> 「よく買うのに判定されない食材」が出てきたら、辞書に1行足すだけで覚えます。

## 🚀 ローカルで動かす

```bash
npm install
npx prisma generate
npm run dev          # http://localhost:3000
```

環境変数（`.env.local`）は任意。未設定ならローカルSQLite（`prisma/dev.db`）に自動フォールバックします。
本番のTurso接続を使う場合のみ以下を設定:

```
TURSO_DATABASE_URL=libsql://...
TURSO_AUTH_TOKEN=...
```

> `.env.local` は `.gitignore` 済み。トークンはコミットされません。
